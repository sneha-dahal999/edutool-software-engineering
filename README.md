## Project
Edutool.com is a planned responsive e-book library management system with account management, catalogue browsing, search, OCR-assisted search and personalised recommendations.

## Technology direction
- Front end: HTML, CSS, JavaScript
- Application layer: Python / Flask
- Database: MongoDB
- Version control: Git / GitHub
- Modelling: Lucidchart
