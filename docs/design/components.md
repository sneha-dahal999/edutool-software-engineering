# Component Design

| Component | Main responsibility |
|---|---|
| Authentication | Registration, login, logout and account access |
| Catalogue | Book records, categories and browsing |
| Search/NLP | Natural-language search and matching |
| OCR | Image-to-text extraction for search |
| Recommendation | Planned personalised suggestions |
| User interaction | Wishlist and book interactions |
| Persistence | Communication with MongoDB |

The design aims for high cohesion by keeping related work together and lower coupling by using clear component interfaces.
