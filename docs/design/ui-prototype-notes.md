# UI Prototype Notes

The planned interface is responsive and keeps the main search action visible.

## Main screens
1. Home/search
2. Search results
3. Book details
4. Login/register
5. User profile and saved books
6. Administrator dashboard

## Design principles applied
- User control
- Clear navigation
- Consistent labels and actions
- Reduced memory load
- Responsive presentation

The prototype should be reviewed with the team before implementation and revised from genuine feedback.
