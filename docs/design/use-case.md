# Use Case Design

## Actors
- Guest
- Registered User
- Administrator

## Main use cases
- Browse catalogue
- View book details
- Register and log in
- Search the library
- Use OCR-assisted search
- Save and interact with books
- Receive recommendations
- Manage books and categories
- Manage users

The use-case model represents the requirements from the user's point of view and keeps the system boundary clear.
