# Requirements Elicitation Notes

The project requirements are based on the agreed Edutool.com scope and user roles from Assessment 2. The main stakeholder views considered are guest, registered user, administrator and the project team.

## Elicitation focus
- What should guests be able to see?
- What tasks should registered users complete?
- What management tasks should administrators perform?
- What information and quality constraints affect the system?
- Which functions must be delivered first?

No interview or survey result is claimed here. These notes document the agreed project scope and questions that can be used in future review sessions.
