# MoSCoW Priorities

| Priority | Edutool.com items |
|---|---|
| Must Have | Account access, catalogue, administration, natural-language search, security and responsive usability |
| Should Have | OCR search, wishlist and related user features |
| Could Have | Personalised recommendations, ratings and comments |
| Won't Have | Native mobile app and full AI tutoring system in the first release |

The priority list follows the project scope already established for Edutool.com. Priorities can be reviewed if approved requirements change.
