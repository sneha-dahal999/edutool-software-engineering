# Requirements

## Functional requirements
- FR1: Users can register, log in, log out and manage an account.
- FR2: Users can browse, filter and view the e-book catalogue.
- FR3: Administrators can manage books, categories and user accounts.
- FR4: Registered users can perform natural-language book searches.
- FR5: Users can use OCR-assisted image-to-text search.
- FR6: Registered users can save books and interact with book records.
- FR7: The system can provide personalised recommendations.

## Non-functional requirements
- NFR1: Security and privacy must protect accounts and restrict access.
- NFR2: The interface should be usable and responsive.
- NFR3: Important data should support backup and recovery.
- NFR4: The software should be maintainable through modular design and version control.

## Scope
The first release focuses on the core account, catalogue, administration and search functions. OCR and recommendations are planned project features. Native mobile applications and a full AI tutoring system are outside the first release.

## Acceptance indicators
Acceptance indicators are planning checks. They must be verified by actual testing before being reported as passed.
