# QA Checklist

- [ ] Requirements reviewed for ambiguity and missing information
- [ ] Use-case and sequence models reviewed
- [ ] Architecture and component responsibilities checked
- [ ] Code reviewed before integration
- [ ] Unit tests executed
- [ ] Functional tests executed
- [ ] Integration/system tests executed
- [ ] UI tests executed
- [ ] Regression tests repeated after fixes
- [ ] User acceptance testing completed
- [ ] Defects recorded and retested
- [ ] Final repository evidence captured

This checklist separates planned quality activities from completed evidence.
