# Test Plan

Testing follows the unit concepts of verification and validation.

## Planned test levels
- Unit testing
- Functional testing
- Integration/system testing
- User-interface testing
- Regression testing
- User acceptance testing

## Planned test techniques
- Black-box testing for visible behaviour
- Equivalence classes where input groups differ
- Boundary testing where limits exist
- Regression testing after fixes

Actual results must be recorded after the tests are executed. This repository does not claim unexecuted tests have passed.
